## 1. 当前模块状态

### 台账 / 记录器

状态：阶段性完成，P3 暂停。

已完成：

- 实时记录：开始、暂停、继续、完成。
- 暂停点：记录中可添加节点。
- 跨天记录：底层不拆，日视图与报表虚拟裁剪。
- 事后校准：可修改已完成片段开始/结束时间。
- 补记片段：支持手动补录一段工作时间。
- 事后切分：支持添加/编辑切点并按标签拆分。
- 剪辑台交互：缩放、横向拖动、色块边缘拖拽、磁吸相邻片段、秒级调整。
- 同标签闭环：
  - 拆分后相邻片段改为同标签时自动归并。
  - 同标签暂停点确认合并时可清理暂停点，文字记录追加到片段备注中。

当前决策：

- 不做台账 P3。
- 发布时测试历史数据会清理，不处理历史脏数据治理。
- 不支持外部台账数据导入时，重叠修复/冲突治理暂不需要。

后续仅在真实使用高频触发时再考虑：

- [ ] 轻量撤销最近一次台账编辑。
- [ ] 合并非严格相邻但间隔极短的同标签片段。

### 活动轨迹 / 被动线索

状态：P1 首轮实现完成，待人工使用验证。

设计边界：

- `activity_log` 是原始传感器流水，不因台账拆分/合并而物理修改。
- 活动线索只作为辅助，不直接计入正式工时。
- 正式统计仍以用户确认过的 `time_entries` 为准。
- 轨迹转台账必须裁剪到空白区间，不覆盖已有台账。

已完成：

- 前台窗口采样：窗口标题、进程名、idle 秒数、是否空闲。
- 隐私脱敏：默认关闭；开启后命中敏感进程或标题关键词时隐藏标题。
- 活动线索聚合：按活动/idle、进程和时间间隔合并。
- 未记录活动：按正式台账空白区间虚拟裁剪，支持补记为台账。
- 记录内 idle：可一键按轨迹切成“原标签 → 摸鱼/暂停标签 → 原标签”。
- 忽略线索：写入 ignored suggestions，不修改原始轨迹。
- 台账页视觉：正式片段为实体色块，活动轨迹为低高度半透明虚线/雷达带，视觉语义区分。
- 设置页：被动活动记录开关、采样间隔、空闲阈值、最短线索。
- 设置页：敏感进程、敏感标题关键词、噪声进程、噪声标题可配置。
- 历史轨迹展示：忽略/系统噪声进程和标题按空闲处理，不物理修改原始 activity_log。

待人工验证：

- [ ] 台账页活动轨迹是否与正式片段有足够视觉区分。
- [ ] 长时间无键鼠输入时是否生成“记录中疑似离开”。
- [ ] “按轨迹切分”是否符合预期，是否需要把“摸鱼”改名为更中性的“暂停/离开”。
- [ ] 未记录活动补记时是否只补空白区间。
- [ ] 忽略线索是否不会影响原始 activity_log。
- [x] 敏感窗口脱敏策略确认默认关闭，避免过度黑箱；用户可在设置中开启并配置关键词。

下一步建议：

- [ ] 活动线索支持手动微调起止时间后再补记。
- [ ] 活动轨迹列表增加进程/应用筛选。
- [ ] 忘记开始/忘记停止提醒。
- [ ] 证据链导出时引用截图附近活动轨迹作为上下文。

### 证据模块

状态：P1.5 已完成一轮实现与人工验证，进入发行前收口。

已完成：

- 证据库结构：`牛马联盟证据库/`。
- 数据库表：`evidence_items` / `evidence_metadata` / `evidence_reviews`。
- 截图安全入库：
  - raw 原件目录：`captures/YYYY/MM/DD/raw/`。
  - 临时文件写入后 rename。
  - 计算 sha256。
  - 文件名使用时间 + 类型 + hash，不拼窗口标题。
  - metadata JSON 写入 `meta/`。
  - 原始截图不加水印、不压缩、不覆盖。
- 多屏截图：F10 默认截鼠标所在显示器，截图前 80ms 二次取点降低误判。
- 手动导入材料：
  - 复制到 `files/YYYY/MM/DD/raw/`。
  - 原文件不修改。
  - 计算 sha256、类型、大小、MIME、导入元数据。
  - 音频/视频/压缩包/未知类型安全入库并标记 unsupported。
- 证据工作台 UI：
  - 证据列表、绝对路径展示、打开原件所在文件夹。
  - 图片预览和基础元数据展示。
  - 日期日历与状态/类型/台账关联筛选。
  - 人工复核：标题、状态、备注、标签、关联台账。
  - 页面“立即截图”入口隐藏，截图统一使用 F10，避免切换窗口过慢截错。
- 材料导入：先选择证据归档日期，再选择文件；前后端均禁止未来日期。
- 证据库迁移：选择新位置后二次确认，复制并校验 size/sha256，成功后切换配置，旧目录保留。
- 证据链导出：支持单日/多日 Markdown，生成原始材料副本、打包清单和未处理材料说明，不修改 raw。
- 证据删除后端接口：同步删除 raw、meta 和数据库索引，UI 暂未开放。
- 设置页文案：
  - 明确 raw 原件永久保留。
  - 水印仅用于未来导出副本。
  - 保留天数仅指未来缩略图/缓存，不影响原件。
