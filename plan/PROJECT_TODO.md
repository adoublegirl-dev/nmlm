## 1. 当前模块状态

### 台账 / 记录器

状态：阶段性完成，P3 暂停。

已完成：

- 实时记录：开始、暂停、继续、完成。
- 暂停点：记录中可添加节点。
- 跨天记录：底层不拆，日视图与报表虚拟裁剪。
- 事后校准：可修改已完成片段开始/结束时间。
- 补记片段：支持手动补录一段工作时间。
- 事后切分：支持添加/编辑切点并按标签拆分。
- 剪辑台交互：缩放、横向拖动、色块边缘拖拽、磁吸相邻片段、秒级调整。
- 同标签闭环：
  - 拆分后相邻片段改为同标签时自动归并。
  - 同标签暂停点确认合并时可清理暂停点，文字记录追加到片段备注中。

当前决策：

- 不做台账 P3。
- 发布时测试历史数据会清理，不处理历史脏数据治理。
- 不支持外部台账数据导入时，重叠修复/冲突治理暂不需要。

后续仅在真实使用高频触发时再考虑：

- [ ] 轻量撤销最近一次台账编辑。
- [ ] 合并非严格相邻但间隔极短的同标签片段。

### 证据模块

状态：P1 开发中，当前实现已完成一轮，待人工验证。

已完成：

- 证据库结构：`牛马联盟证据库/`。
- 数据库表：`evidence_items` / `evidence_metadata` / `evidence_reviews`。
- 截图安全入库：
  - raw 原件目录：`captures/YYYY/MM/DD/raw/`。
  - 临时文件写入后 rename。
  - 计算 sha256。
  - 文件名使用时间 + 类型 + hash，不拼窗口标题。
  - metadata JSON 写入 `meta/`。
  - 原始截图不加水印、不压缩、不覆盖。
- 多屏截图：F10 默认截鼠标所在显示器，截图前 80ms 二次取点降低误判。
- 手动导入材料：
  - 复制到 `files/YYYY/MM/DD/raw/`。
  - 原文件不修改。
  - 计算 sha256、类型、大小、MIME、导入元数据。
  - 音频/视频/压缩包/未知类型安全入库并标记 unsupported。
- 证据工作台 UI：
  - 证据列表。
  - 图片预览。
  - 基础元数据展示。
  - 人工复核：标题、状态、备注。
- 设置页文案：
  - 明确 raw 原件永久保留。
  - 水印仅用于未来导出副本。
  - 保留天数仅指未来缩略图/缓存，不影响原件。

待人工验证：

- [ ] 截图 raw 文件是否进入 `captures/YYYY/MM/DD/raw/`。
- [ ] meta JSON 是否生成在同日 `meta/`。
- [ ] 证据列表图片预览是否正常。
- [ ] 手动导入图片/PDF/文档/视频/压缩包是否都能入库。
