## 领域术语

权威词汇见根目录 `CONTEXT.md`：

- **记录**：只有“进行中”与“已完成”，没有暂停状态。
- **切点**：记录内部的时间边界；从切点起可归类后续时间段，不停止记录。
- **关键帧 / marker**：视觉与语义标记，不改变时长或类型。当前“打关键帧”动作会同时创建一个切点，便于归类右侧时间段。

数据库物理表仍为 `pause_points`，仅为兼容历史本地数据；代码仓储、IPC 和界面术语统一为 `timelinePoints` / “切点”。不要为改表名创建破坏性迁移。

## 当前交互规则

### 记录器与快捷键

- 默认窗口 `280×390`；迷你窗口 `280×168`。
- F8：空闲时开始记录；记录中打关键帧。F9：停止记录。
- 记录器中不再有暂停/继续按钮、暂停计时或 `is-paused` UI。
- 默认模式中的工作类型选择器：
  - 未开始：`选择工作类型 + 当前值`，设置下一次记录初始类型；
  - 记录中：`修改当前工作类型 + 当前值`，打开完整工作类型面板并修改当前活跃段。
- 点击时间轴上的具体时间段，才打开其上方的小型段类型菜单；两种菜单写同一段数据，修改后互相刷新。

### 时间轴

- 默认模式和迷你模式共用同一个时间轴组件、数据和交互逻辑；默认模式刻度常驻、轨道更高，迷你模式紧凑显示。
- 默认缩放为 **30 分钟**；档位：`24h / 12h / 6h / 3h / 1h / 30m / 15m / 5m`。
- 滚轮以指针时间为锚缩放，空白处可拖拽平移。5 秒无操作后回到当前时间附近和默认缩放。
- 视口重置与 hover 视觉严格解耦：鼠标仍在时间轴内时，拖拽后即使视口重置，背景不可消失；仅真实移出或窗口失焦恢复透明。
- 时间轴背景默认透明；hover/拖拽时为 `rgba(246, 242, 225, .25)`。
- 刻度包含全天视图末端 `24:00`。

### 关键帧与切点渲染

- marker 独立持久化，不依赖切点；切点负责分段，marker 负责关键帧视觉。
- marker 在渲染层对时间段形成真实透明挖空，露出下方视频；挖空比 icon 大 6px。
- icon 位于最上层，并随缩放变化：24/12h 8px、6/3h 9px、1h 11px、30m 13px、15/5m 14px。
- 已修复完成记录的切点未载入导致两侧 tooltip 都显示完整区间的问题；tooltip 应与实际分段和刻度一致。

### better-sqlite3 测试 ABI 问题

- `tests/ledger.test.js` 目前无法在 Vitest 的 Node 运行时执行：本地 `better-sqlite3` 原生模块编译给 Electron（`NODE_MODULE_VERSION 125`），Vitest 所用 Node 需要 ABI 137。
- 影响：应用 Electron 运行时不受影响；但台账服务测试会在加载数据库前全部失败，无法为后端改动提供自动回归保障。
- **不要直接执行 `npm rebuild` 或重新安装该模块以迁就 Vitest**，那可能使 Electron 无法加载数据库。
- 后续应在独立测试环境维护 Node 版原生模块，或使用 Electron 测试运行器/CI 执行台账服务测试；完成前，后端改动需增加 Electron 端实际验证。
